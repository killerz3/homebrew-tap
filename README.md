# killerz3/homebrew-tap

Homebrew formulae for things I build.

```sh
brew install killerz3/tap/ridealong
```

| Formula | What it is |
| --- | --- |
| [`ridealong`](Formula/ridealong.rb) | One logged-in browser for you and your AI agents. [ridealong.kz3.dev](https://ridealong.kz3.dev/) |

## Updating a formula

Bump `url`/`version`, then set `sha256` to `shasum -a 256` of the new release asset.
